# 13. Login/Register Cleanup (Shared Password Input, Cancelled-Query Fix)

**Status:** ✅ Done

- **Shared `PasswordInput` component:** extracted the ~20-line password show/hide toggle (state, wrapper, input, icon button) that was duplicated verbatim between `login/page.tsx` and `register/page.tsx` into `components/PasswordInput.tsx`, taking `value`/`onChange`/`disabled`/`minLength` props. Register keeps its `minLength={8}`.
- **Accessibility fix:** the show/hide toggle button had no accessible name — added `aria-label` (`"Show password"` / `"Hide password"`) and `aria-pressed` so screen readers announce its purpose and current state.
- **`AdminDashboard.tsx` cancelled-query fix:** replaced `statsQuery.error.message !== "CancelledError"` (a string match that only happened to work because `CancelledError`'s constructor calls `super("CancelledError")`) with `!(statsQuery.error instanceof CancelledError)` from `@tanstack/react-query` — the string check would misfire on a library upgrade or a real error that happened to share that message.
- **Backend companion fix:** removed a debug log in `create-admin.ts` that printed the admin password/Mongo URI in plaintext (see backend entry 20).
